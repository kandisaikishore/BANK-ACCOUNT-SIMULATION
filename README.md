# Bank Account Simulation — Java

An educational Java project that models basic bank-account operations using object-oriented programming concepts.

## Features

- Create an account
- Deposit and withdraw funds
- Record transaction history
- Model a savings account using inheritance
- Demonstrate method overriding for withdrawal behaviour
- Calculate interest where implemented

## Technology

- Java
- Classes, inheritance, and method overriding

## Run locally

Install a JDK, clone the repository, then compile and execute the class containing `main`. For a default-package project:

```bash
git clone https://github.com/saikishore2410/BANK-ACCOUNT-SIMULATION.git
cd BANK-ACCOUNT-SIMULATION
javac *.java
java Main
```

Replace `Main` with the actual entry-point class name if necessary.

## Important scope note

This is a learning simulation—not a real banking system. It should not be used to store real financial data or process real money.
